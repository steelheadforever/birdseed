Motion filter — discard empty clips

The PIR fires on any IR change — wind, sun, shadows — not just birds. After each clip a cheap frame-difference pass scores how much actually moved; clips below the threshold are deleted as empty motion. Start at 0 (keep everything), watch the “Motion · last clip” card as real birds and false triggers come in, then set the threshold just above the empty-clip floor. Note: this catches still scenes, not a wind-shaken camera — that needs a rigid mount.
